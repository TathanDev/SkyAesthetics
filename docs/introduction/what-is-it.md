# What is Sky Aesthetics

Sky Aesthetics is a library that allow anyone to change the Minecraft sky with simple resource pack.

## What can be made
Here are some possibilities you can do with the mod:

- Add any object in the sky (like new moons, planets, etc.) 🪐
- Modify sun/moon texture/size/position 🌔
- Modify stars 🌠
  - size
  - color
  - movement
- Modify Clouds ☁️
- Modify Rain 🌧️
- Change the color of the sky/sunset 🌅
- Custom Skybox 🌌
